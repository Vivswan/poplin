# Publish and share

What an agent or a person does with an install.

| Page                                            | What it covers                                                  |
| ----------------------------------------------- | --------------------------------------------------------------- |
| [Publish](publish.md)                           | publish, name, and update a site                                |
| [Who can open a site](who-can-open.md)          | private, unlisted, public, the address, a new link              |
| [Manage sites](manage-sites.md)                 | show, list, go back, copy, delete, restore, the other settings  |
| [Back up](back-up.md)                           | export and import                                               |
| [The agent tools](agent-tools.md)               | the tools an agent gets                                         |
| [When poplin refuses](when-poplin-refuses.md)   | every refusal and what to do                                    |

```text
You:    Put this report online.           ->  the agent calls publish_site
You:    Share it with anyone I send it.   ->  the agent calls update_site, access unlisted
You:    Take it down.                     ->  the agent calls delete_site
```

An agent uses the tools. A person uses the commands. Both do the same things.
