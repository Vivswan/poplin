# Install with an agent

How an install starts when your agent leads it: the agent follows [the skill's setup page](../../skills/poplin/references/setup.md) through the same steps as [By hand](by-hand.md).

**The quickest way is to ask your agent.** Paste the line of [the README](../../README.md#use-it-from-an-ai-agent) into it: it tells you what to click and checks each step.

The agent acts as you, with the login [step 6](by-hand.md#the-steps) saved on this computer: it does not log in itself, and it needs no address from you. It asks before it adds poplin's tools to its own configuration as an MCP server, which is how an agent gets tools. A chat in a browser cannot run commands, so it cannot publish.
