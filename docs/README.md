# Poplin

Your AI agent, or you at the command line, publish a static site (a folder, or one HTML file) to your own Cloudflare account and get a link.

```text
You:    Put this report online.

Agent:  Published. It is private: only the users of your install can open it, after they log in.

        https://report--k3f9x2ab71qz-p-poplin.example.com
```

| Folder                              | What it holds                                   |
| ----------------------------------- | ----------------------------------------------- |
| [Start](start/README.md)            | get your own install, under a domain or without |
| [Sites](sites/README.md)            | publish and share                               |
| [Dashboard](dashboard/README.md)    | the screens, one by one                         |
| [Upkeep](upkeep/README.md)          | update, back up, and remove the install         |
| [Fix](fix/README.md)                | when something fails, or nobody can log in      |
| [About](about/README.md)            | security and the build                          |

The examples write `poplin`. Type `npx poplin` in its place, as [Install](start/install.md) does, unless you ran `npm install -g poplin` on the computer. `example.com` stands for your own domain. An install [without a domain](start/without-a-domain.md) has other addresses, and that page shows them.
